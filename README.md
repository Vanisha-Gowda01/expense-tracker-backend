# Expense Tracker Backend API

A professional backend project built using FastAPI with JWT Authentication, CRUD APIs, SQLite Database, SQLAlchemy ORM, and Analytics APIs.

## Features

- JWT Authentication
- User Management
- Expense Tracking
- Income Tracking
- Analytics APIs
- CRUD Operations
- SQLite Database
- SQLAlchemy ORM
- Swagger Documentation

## Technologies Used

- Python
- FastAPI
- SQLAlchemy
- SQLite
- JWT
- Uvicorn
